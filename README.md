# Data Analytics Portfolio

Hi, I'm Kayode Alao, an aspiring data analyst building practical, business-focused analytics projects.

This repository documents my progression from data preparation and Excel analysis into more advanced analytics tools. The emphasis is on **solving business problems, making defensible analytical decisions, and communicating results clearly**.

An interactive Excel dashboard built from a personal-finance dataset, with emphasis on financial-risk analysis and dashboard communication.

**Focus:** Excel · PivotTables · Charts · Slicers · Dashboard design · Analytical reasoning

## Approach

My learning approach is project-first:

1. Start with a real analytical problem.
2. Understand and prepare the data.
3. Analyze the data using the appropriate tool.
4. Document important decisions and assumptions.
5. Communicate the result.
6. Improve the project based on review and feedback.
