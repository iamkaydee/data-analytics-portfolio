# Project 01 — Retail Sales Data Cleaning

## Overview

This project focuses on preparing a messy retail/e-commerce sales dataset for analysis in Microsoft Excel.

It was an early practical project focused on identifying common data-quality problems, cleaning the data, and preparing it for downstream analysis.

## Data Quality Issues

- Mixed date formats
- Quantity values stored as text and/or missing
- Price values stored as text and/or missing
- Inconsistent category capitalization

## Cleaning Activities

- Standardized dates
- Cleaned numeric fields
- Identified and handled missing values
- Standardized category text
- Calculated total sales

**Formula:** `Total = Quantity × Price`

## Tool

- Microsoft Excel

## What I Learned

- Raw business data is rarely analysis-ready.
- Data types matter for calculations.
- Inconsistent categories can distort analysis.
- Missing values require deliberate treatment.
- Cleaning decisions should be documented.
