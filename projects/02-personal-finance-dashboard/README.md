# Project 02 — Personal Finance Dashboard

## Overview

An interactive Excel dashboard built from a synthetic personal-finance dataset.

The project focuses on transforming a large dataset into an interactive dashboard that summarizes financial characteristics and highlights higher-risk records.

## Tools

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Timeline
- Excel formulas/helper fields

## Project Components

- Data preparation
- Summary KPIs
- Pivot-based analysis
- High-risk analysis
- Interactive filtering
- Dashboard presentation

## Analytical Note

The original project used filtering rules involving DTI and savings-to-income ratio. These rules should be documented as **project-specific data assumptions**, not presented as universal financial truths, unless the underlying field definitions and business context support them.

The project should also preserve the distinction between raw data and the filtered analysis dataset, particularly because the filtering removed a substantial proportion of the original records.

## Status

**Completed — requires analytical/documentation refinement**

The dashboard is functional and visually developed, but the data-cleaning rationale and business interpretation should be strengthened before treating it as a polished flagship portfolio project.
