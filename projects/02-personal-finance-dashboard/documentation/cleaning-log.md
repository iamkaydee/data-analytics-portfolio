# Cleaning Log

## Current Documented Transformations

The original project notes document two major filtering rules:

1. DTI > 2 was removed.
2. Savings-to-income ratio > 1 was removed.

The notes indicate that these filters reduced the dataset substantially, to approximately 2,495 records.

## Methodological Review Required

These filters should not be described simply as universally “impossible” financial conditions.

Before finalizing the project:
- Verify the definitions of DTI and savings-to-income ratio.
- Establish whether the values are valid according to the dataset's generation/business rules.
- Document the rationale for each exclusion.
- Compare dashboard results before and after filtering.
- Preserve the original dataset.

## Principle

A data-cleaning rule should be supported by the data definition or a clearly stated business requirement.
