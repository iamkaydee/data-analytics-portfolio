# Analysis Notes

## Objective

Use the personal-finance dataset to explore financial characteristics and identify higher-risk records through an interactive Excel dashboard.

## Dashboard Components

The completed dashboard includes:
- Summary cards
- PivotTables
- Charts
- High_Risk helper field
- Slicers
- Timeline

## Methodological Review

The original analysis applied filters including:
- DTI greater than 2
- Savings-to-income ratio greater than 1

These rules need careful interpretation.

A ratio above a threshold is not automatically evidence that a record is impossible or erroneous. The meaning depends on the dataset's definitions, units, time period, and intended business context.

## Next Improvement

Before final portfolio publication:
1. Verify the source field definitions.
2. Reassess the filtering rules.
3. Compare results before and after filtering.
4. Document how many records are affected.
5. Explain why each rule is appropriate.
6. Preserve the raw dataset separately from the analysis-ready data.
