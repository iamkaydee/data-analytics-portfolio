# Excel Cheat Sheet

## Common Functions

### XLOOKUP

```excel
=XLOOKUP(lookup_value, lookup_array, return_array)
```

### VLOOKUP

```excel
=VLOOKUP(lookup_value, table_array, col_index_num, FALSE)
```

## Useful Analysis Areas

- Sorting and filtering
- Conditional formatting
- Excel Tables
- PivotTables
- PivotCharts
- Slicers
- Timelines
- Basic date and text functions
- Data cleaning and standardization

## Principle

Use Excel features because they solve an analytical problem, not simply because they are available.
